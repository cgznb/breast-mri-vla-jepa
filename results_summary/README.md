## 配置与复现范围

这是已完成实验的汇总快照，未随源码发布训练数据或模型权重。CSV 保留原始指标精度，移除了机器路径；Markdown 仅四舍五入显示。

七种实际设置为 A0、A1、A2、L1、L2、L3、L4，每种有固定 T0/动态两版和种子 17/43。配置位于 `../configs/registered_roi32_epoch200*.yaml`，具体配对与损失定义见 [实验框架](../docs/EXPERIMENTS_ZH.md)。L0 是已有基线的别名：固定版为 A1，动态版为 A2。

训练使用 764 人，开发验证 102 人；最多 200 epoch、patience 50、batch 16。没有独立测试集。这些结果不能作为独立测试或临床验证结果。动态验证枚举 382 个合法前缀，并按患者等权计算选模 NLL。

动态 L1 两种子平均选模 NLL 为 0.5490，动态 L0 为 0.5589；平均 T0 AUROC 为 0.7406 和 0.7212。动态 L2 平均选模 NLL 为 0.5620，best 自主状态误差相对 copy 的平均比值为 0.9689；其中只有种子 17 的 best 比值小于 1。两种子与同一开发集上的差值不能证明稳定的泛化改进。各组训练末期均出现分类过拟合，应保留 best/last 的区别。
